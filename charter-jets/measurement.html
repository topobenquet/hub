Measurement Plan

Starting point: there is nothing

Audit of the HTML served by the campaign landing page on August 31, 2026:

gtag                0 occurrences
googletagmanager    0
G-  / AW-           0
dataLayer           0

Zero tags. No GA4, no Google Ads, no tag manager, no pixel. The only analytics is Lovable's built-in counter, which cannot be used to optimise campaigns.

At $10,000 a month with no measurement, the campaign optimises blind. This blocks launch.

Architecture

Landing page ──► dataLayer ──► GTM ──► GA4 ──► Google Ads (imported conversions)
                                 └───► Google Ads (direct tag, enhanced conversions)
CRM / sales team ─────────────────────► Google Ads (offline conversions, real value)

Events the landing page already emits

The page is already instrumented. These fire today and are waiting for a container to receive them:

Event Source What it means
generate_lead (with lead_source) Landing page forms Primary form conversion
avinode_search_one_way / _round_trip / _multi_city Search widget The visitor searched
avinode_search_empty_leg Search widget Searched empty legs
avinode_open_inquiry_form Search widget High intent
avinode_send_inquiry / avinode_send_lead Search widget Primary search conversion
avinode_change_airport / _date / _pax / _currency Search widget Abandonment diagnostics

One thing worth understanding about the search widget: it is a cross-origin iframe served by Avinode. Google Ads and GA4 cannot see inside it. The only telemetry we get from the search is the bridge the landing page builds from Avinode's own tracking events into the data layer. If that bridge breaks in a future change, the entire search funnel goes dark without any error appearing.

Enhanced conversions for leads: the landing page already stores the Google click identifier (gclid, plus gbraid, wbraid and the Microsoft equivalent) and the campaign parameters against every lead it captures. That is precisely what is needed to upload offline conversions later. It is the piece that separates an account that scales from one that plateaus, and it is already built.

Call tracking: the biggest gap

The phone button sits in the header and in the closing section of the landing page. In private charter, a significant share of the highest value leads will call rather than fill in a form. Today those calls are not attributed to any campaign or keyword.

Options, in order of preference:

  1. Google Ads native call tracking, using forwarding numbers and call extensions. Free and integrates by itself, but only covers calls originating from the ads.
  2. CallRail or WhatConverts, with dynamic number insertion. Covers all traffic and records calls, which additionally gives the sales team a way to score lead quality. The cost is small relative to the media budget.

Our recommendation is option 2, because the same move also solves lead quality scoring, which is what feeds the offline conversion import in phase 2.

One detail that affects either choice: the same phone number is published on charterjetsinc.com and on the campaign landing page. These are separate properties, so whatever is implemented has to cover both, or a share of calls stays invisible.

Avinode and GA4

The Avinode web app accepts a GA4 measurement ID directly in its own settings, along with an analytics referrer URL. Without the referrer set, traffic from the widget is attributed in GA4 as coming from apps.avinode.com, which breaks attribution for every search.

Setting it regenerates the embed token, which means the landing page has to be updated at the same time. We will do this in one pass together with the GA4 setup rather than touching the page twice.

Why Clarity is on that list

At roughly 700 clicks a month, there is not enough traffic for statistically valid A/B testing. A two-armed test would take more than a year to resolve. Clarity is free, works at any traffic level, and answers the questions statistics cannot answer at this volume: does anyone scroll to the form at the bottom, do people click the aircraft category cards, do they leave while the search widget is still loading.

For the first few months, that qualitative signal is worth more than a test we cannot power.
