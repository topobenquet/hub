Shared Negative Keyword Lists

Eight lists, built on the account's 1,870 real search terms, not on a generic template. The term by term evidence, with actual cost, is in the term by term waste breakdown kept with the account audit.

How to load them: Tools → Negative keyword lists → +, one list per block below, then apply all 8 to every campaign. One exception: list 2 (Price Curiosity) is not applied to S | Pricing-Research.

Notación: -kw = amplia, -"kw" = frase, -[kw] = exacta. General rule: broad match for concepts, exact match for specific queries that do carry comprar en otra variante.

What to do with the 713 existing negatives

Do not migrate them as they are. They were built by patching and they mix criteria.

  1. Create the 8 lists above, clean.
  2. Apply them to the 7 new campaigns.
  3. Leave the old ones where they are. The old campaigns get paused, not deleted.
  4. Watch Search_GA: today it runs without the shared list applied. If it is ever reactivated, apply the list first.

Maintenance routine

Cuándo Qué
Cada 48 h, primeras 2 semanas Revisar search terms y sumar negativas
Semanal, después Ídem
Monthly Check that no negative is blocking a keyword we actually want (Tools → Keyword Diagnosis)

Even on exact match, close variants will still get through. The negative list is never finished, and in this vertical it is half the job.
